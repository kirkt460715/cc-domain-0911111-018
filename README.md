# 分能 工业能耗区间核算

把累计表计重建为能量区间，再按生产日历分配、计算需量、费用和排放。能量内部使用微 kWh，费率为货币/kWh；输入时刻需要明确偏移。

## 负荷形态聚类

`energyflow/load/` 在重建后的窗口功率之上构建生产日曲线并识别负荷形态：

- **生产日曲线**：按生产日起点（固定时区偏移）、固定网格宽度（须整除 86400 秒）和覆盖率阈值，把重建区间精确积分到网格。跨日区间按时间比例切到两侧；换表后新表段从安装基线生成首区间，能量不丢、不重复。
- **零负荷与缺测分离**：表计持平的零负荷单元格保留显式 `0/1`；没有测量覆盖的单元格为 `null`，绝不补零。部分日按真实覆盖率返回，不进入聚类、不伪装成完整日；全零日单独标记处理。
- **形态归一化**：聚类输入按日总量归一化到单位和，因此日总量相近但时段分布不同的白班/夜班可以分开；日总量仍原样保留在曲线记录中供业务查看。
- **确定性聚类**：仅用标准库与精确分数，k-means++ 初始中心来自固定种子的 SHA-256 随机源，相同输入与种子逐字节复现。返回真实代表日（距中心最近的实际日）、簇规模、成员距离、簇内惯性和轮廓系数。
- **冻结与归类**：训练结果连同参数、种子、代表形态和读数血缘写入不可变模型。后续日期只对照冻结中心归类，超阈值标记 `new_pattern` 而不强行塞入；重复运行不会让历史标签跳动。
- **版本比较**：两个模型按共同日期解释分裂、合并与改归属，并保留到重建区间 id 的血缘。所有负载表都带指纹，纳入存储完整性校验。

```sh
python3 -m energyflow demo   # 演示末尾包含白班/夜班形态聚类与版本合并
```

## 运行环境

使用 Python 3.11，核心功能依赖标准库和 SQLite。演示和测试只使用本地合成数据，不需要账户、设备或外部运行服务。请从项目根目录执行命令。

## 检查与运行

构建检查验证语法，测试使用临时数据目录，不会连接远端服务。

```sh
python3 -m compileall -q energyflow
python3 -m unittest discover -s tests -v
python3 -m energyflow demo
```

演示会展示产品的实际数据处理和输出，运行结束自行退出。查看现有接口：

```sh
python3 -m energyflow --db :memory: describe
```

## 目录与数据

energyflow/ 保存领域逻辑和请求入口，tests/ 包含正常行为、边界与恢复测试。例子中的标识和记录为合成资料，不包含真实人员或生产测量。业务目录和本地数据库由调用者指定，应与源码分开保存。

## 干净环境复现

容器定义固定运行时版本。构建时准备环境，运行时无需网络；每次启动会复制只读源码到临时工作目录，测试产生的文件不会写回仓库。

```sh
docker build -t local-product-check .
docker run --rm --network none local-product-check
```
